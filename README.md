# Data Professional Survey Dashboard

Interactive Power BI dashboard analyzing survey data from data professionals around the world.

## About This Project
This dashboard explores
- Average salary by job title
- Work/life balance satisfaction
- Salary satisfaction
- Favorite programming languages
- Difficulty entering the data industry
- Respondent distribution by country

## Tools & Skills
- Power BI
- Power Query
- Data Cleaning
- Data Visualization

## Key Findings
- Data Scientists have the highest average salary
- Python is the most popular programming language
- Most survey participants are from the United States
- Work/life balance satisfaction is relatively moderate
